### Read-only verification extension prepared after this inventory

The inventory script now has a contract-tested optional extension; **its new fields have not yet been read from Apple on the revised source**. Earlier reports cannot supply the following results retroactively:

- Availability: read `apps/{id}/appAvailabilityV2`, then all `v2/appAvailabilities/{id}/territoryAvailabilities` pages. Australia-only configuration requires complete unique territory rows, explicit availability booleans, only AUS enabled and availableInNewTerritories:false. It does not assert the app is already public. [Apple availability endpoint](https://developer.apple.com/documentation/appstoreconnectapi/get-v1-apps-_id_-appavailabilityv2), [territory availability endpoint](https://developer.apple.com/documentation/appstoreconnectapi/get-v2-appavailabilities-_id_-territoryavailabilities).
- Price: read the app's configured price schedule and its manual/automatic AUS prices, joining actual related price points and AUD currency. A free price point merely offered in Apple's catalog proves nothing about the app's configured schedule. Missing/overlapping/malformed prices remain unknown; current-date derivation uses the report's UTC date and holds near date boundaries because the response lacks territory-timezone semantics. This is download pricing, not Plus subscription pricing. [Apple schedule endpoint](https://developer.apple.com/documentation/appstoreconnectapi/get-v1-apps-_id_-apppriceschedule), [manual prices](https://developer.apple.com/documentation/appstoreconnectapi/get-v1-apppriceschedules-_id_-manualprices), [automatic prices](https://developer.apple.com/de/documentation/appstoreconnectapi/get-v1-apppriceschedules-_id_-automaticprices).
- Age: retain the global/legacy rating and `ageRatingOverrideV2` separately, and read the calculated AUS territory rating. Only an actual unique AUS EIGHTEEN_PLUS result establishes `australia18PlusVerified:true`; a declared override alone does not. Apple's older global SEVENTEEN_PLUS value is not silently converted. [Apple territory age ratings](https://developer.apple.com/documentation/appstoreconnectapi/get-v1-appinfos-_id_-territoryageratings), [rating values](https://developer.apple.com/documentation/appstoreconnectapi/appstoreagerating), [override V2 definition](https://developer.apple.com/documentation/appstoreconnectapi/ageratingdeclarationupdaterequest/data-data.dictionary/attributes-data.dictionary).

The transport is GET-only, fixed-origin, redirect-disabled; following pagination must preserve the endpoint, with duplicate/cycle, total-count and ten-page/1,000-row bounds. Optional endpoint failure produces only an allowlisted unavailable status and unknown derived result, never an inferred PASS or raw error body. Privacy labels, agreements, actual reviewer login and screenshot visual review remain outside this extension. No credentials are needed for the no-network contracts.
